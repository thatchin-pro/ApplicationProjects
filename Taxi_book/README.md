A simple Java console-based application that simulates a taxi booking system.
Users can book a taxi, view available taxis and check booking details

## Features
- View all available taxis
- Book a taxi (pickup & drop)
- Calculate trip fare
- Generate booking ID
- Console-based menu

## How to Run
javac -d out src/model/*.java src/service/*.java src/Main.java
java -cp out Main
